Rust Wrapper for ffmpeg so that you can handle all your media files easily.

I kept finding software that was easy to use but everything was so tied down to specific tasks.
Like needing to extract subtitles, convert, and then insert them FOR each file. I wanted
something that could just do everything at once.

![](https://github.com/Mockedarche/multi-media-manager/blob/main/Media/Screen_shot.png?raw=true)

Being a rust program you'll need rust installed and then to build it. I chose rust so I could
make executables and in the future ill likely make a release as an appimage, macOS program, and
windows program but ill wait to see if anyone else uses it first.
